# ci(github): run the gates and the browser suite on every push and pull request

- **Date:** 2026-11-19 17:00
- **Commit:** 1f51f3d
- **Area:** CI

## Problem

Nothing ran onday's checks on a push or a pull request. fmt, clippy, the unit tests and the browser suite ran only when someone remembered to run them locally.

## Cause

The repository had no CI configuration.

## Introduced

none

## Fix

`.github/workflows/ci.yml` runs on every push to `main` and every pull request, in two jobs on `ubuntu-24.04`. `check` runs `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings` and `cargo test --workspace --all-features`. `browsers` runs `cargo test -p onday --test browser -- --ignored` against the Chrome and Firefox the runner image ships, which onday launches headless and finds drivers for itself. Both install the toolchain `rust-toolchain.toml` pins, and the actions are pinned to the commits of their release tags.

## Verified

The workflow parses as YAML, and its toolchain step, `rustup toolchain install`, installs 1.99.0 from `rust-toolchain.toml` under rustup 1.29.3, the runner image's version. Every command the jobs run passed locally on this branch. The workflow itself has not run on GitHub yet.
