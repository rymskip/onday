# build(deps)!: move to thirtyfour 0.38 and release 0.5.0

- **Date:** 2026-11-23 11:15
- **Commit:** b7a59c4
- **Area:** dependencies

## Problem

A project on thirtyfour 0.38 could not use onday 0.4.2: onday re-exports thirtyfour, and its types
come from 0.37, so the two versions' WebDriver and element types do not match.

## Cause

onday required thirtyfour 0.37.5, and 0.38 is a breaking release.

## Introduced

None in onday: thirtyfour 0.38 was released upstream after onday 0.4.2.

## Fix

Require thirtyfour 0.38.3. The code builds unchanged on it. Since `onday::thirtyfour` and the
prelude re-export the new version, the release is 0.5.0.

## Verified

`cargo clippy --workspace --all-targets --all-features -- -D warnings` is clean, and
`cargo test --workspace --all-features` passed 31 tests, and `cargo test -p onday --test browser --
--ignored` passed all 10 browser tests on thirtyfour 0.38.
