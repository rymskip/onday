# build(deps): move to rmcp 3.8.0, which renames ServerInfo to ServerConfig

- **Date:** 2026-10-29 14:05
- **Commit:** 6504070
- **Area:** MCP server

## Problem

`cargo install --path crates/onday_mcp` resolves rmcp 3.8.0 and prints three warnings: `rmcp::model::ServerInfo` is deprecated.

## Cause

rmcp 3.8.0 renamed `ServerInfo` to `ServerConfig` and kept the old name as a deprecated alias. The lock held 3.3.0, so builds from the lock never saw it.

## Introduced

None in onday: the server has always named `ServerInfo`, which rmcp deprecated upstream.

## Fix

Require rmcp 3.8.0 and name `ServerConfig`.

## Verified

`cargo clippy --workspace --all-targets --all-features -- -D warnings` is clean and `cargo test -p onday_mcp` passes on rmcp 3.8.0.
